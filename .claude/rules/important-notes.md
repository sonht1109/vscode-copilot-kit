# Important Notes

**_IMPORTANT_**: Always use Context7 MCP when you need library/API documentation, code generation, setup or configuration steps.

**_IMPORTANT_**: For long running tasks like docker builds, github actions, etc. provide regular updates to the user every 5 minutes.

**_IMPORTANT:_** Never run test suites for whole project unless user asks. Only run test suites for files that have been recently edited.

**_IMPORTANT:_** Never run lint for whole project unless user asks. Only run lint for files that have been recently edited.

**_IMPORTANT:_** Never commit code to git without user approval, or without clear instructions from user to do so.

**_IMPORTANT:_** Always try to leverage subagents to handle independent tasks parallelly.
